# Project / Product Manager

Веду IT-проекты от запроса до запуска: выясняю задачу, формулирую требования и MVP, ставлю задачи разработке (в том числе ИИ-агентам Claude Code и Codex), принимаю и тестирую результат, поддерживаю после релиза.

**Цифры по открытым проектам:** 5 репозиториев · 2 000+ коммитов · 100+ файлов автотестов · в работе с 2025 года.

## Progressor — экосистема из трёх Telegram Mini Apps

Тренировки, питание и добавки в одной подписке. Общее ядро обменивается данными между продуктами и даёт ИИ-подсказки с учётом всех трёх.

| Репозиторий | Что это |
|---|---|
| [progressor_core](https://github.com/MarkKoro/progressor_core) | Общее ядро: единая подписка, пакетная оплата и возвраты, обмен событиями, согласованное обновление всех сервисов с откатом |
| [gym_diary_bot](https://github.com/MarkKoro/gym_diary_bot) | Дневник тренировок: программы, прогресс, режим тренера, рефералы, оплата |
| [food_bot](https://github.com/MarkKoro/food_bot) | Дневник питания: распознавание еды по фото и тексту, КБЖУ и 54 нутриента, обзор дня |
| [supply_bot](https://github.com/MarkKoro/supply_bot) | Трекер добавок: каталог, схемы приёма, напоминания, совместимость |

Демо: [@Progres_App](https://t.me/Progres_App)

## «Креативный мозг» — онлайн-курс под ключ

[ReshalaBot](https://github.com/MarkKoro/ReshalaBot): воронка «бесплатный урок → программа → оплата → доступ в закрытый канал». Оплата через ЮKassa (СБП и Умный платёж), автоматическая выдача доступа, админ-панель, автоответы в Instagram через n8n.

Демо: [@BioMozg_agent](https://t.me/BioMozg_agent) · [Бесплатный урок](https://youtu.be/MeZ4zvrZKpk)
